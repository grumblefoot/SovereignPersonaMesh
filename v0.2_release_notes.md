# Sovereign Persona Mesh (SPM) — v0.2.0 Release Notes

**Release Date:** August 8, 2026  
**Version:** `0.2.0`  
**Target Hardware:** AMD Ryzen AI Max 395 (Strix Halo APU, 128GB Unified RAM)  

---

## 🌟 Highlights & Major Features

### 1. Structured OpenAI Message Architecture for Gemma 4
- Replaced raw string concatenation with native OpenAI structured message payloads (`role: "system"`, `role: "user"`, `role: "assistant"`).
- **Zero System Prompt Echoing**: Prevents internal system directives and metadata blocks from leaking into public character dialogue.
- **Pure Canon Output**: Guarantees clean, in-character dialogue and actions delivered directly to SillyTavern.

### 2. Token Decoupling & Expanded Reasoning Monologue Capacity
- Expanded `MAX_MONOLOGUE_TOKENS` from 500 to **8,192 tokens**, matching backend context capacity.
- **Eliminated Planning Chat Bubbles**: Deep reasoning chains generated during Gemma 4 cognitive processing no longer prematurely force-close monologue mode or spill over into public chat bubbles.

### 3. Real-Time Thought Streaming & Observability Dashboard
- **Web Admin UI (`http://localhost:5050/admin`)**: Real-time SSE streaming for live inner monologue thoughts.
- **Thought History Replay**: 25-entry circular thought history buffer automatically replays previous thoughts when connecting or refreshing the admin dashboard.
- **Dynamic Character Tagging**: Automatically detects SillyTavern character card formats (e.g., `[Seraphina's Personality=...]`, `[Seraphina's body=...]`), tagging thought streams accurately with character names (`[SERAPHINA]`, `[LUNA]`).

### 4. RAG Memory Regeneration & Session Isolation
- **Regenerated Turn Isolation**: RAG memory retrieval (`retrieve_memories`) now filters out current query text (`LOWER(sensory_input) != LOWER(query_text)`).
- **Database Deduplication**: Automatically replaces uncommitted/regenerated turn attempts in PostgreSQL `csa_memory` tables, preventing deleted drafts from bleeding into recalled memories.
