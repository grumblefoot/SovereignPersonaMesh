# Embedding bake-off (decision 4) — 2026-10-05

Harness: `scripts/embed_bakeoff.py`. Corpus: `tests/fixtures/embed_bakeoff_corpus.json`
(58 memories, 32 labelled queries across 6 RP scenarios; queries paraphrase rather than
quote, so scores measure semantic recall). Endpoint: live Lemonade 11.9, `/v1/embeddings`.
The live DB was purged in Sprint 0, so the corpus is representative-synthetic; the harness
accepts a dump of real chat/lore rows whenever one exists.

## Results

| metric | embed-gemma-300m-FLM (NPU) | + gemma task prompts | **Qwen3-Embedding-0.6B-GGUF Q8 (GPU)** |
|---|---|---|---|
| recall@5 | 0.125 | 0.219 | **0.953** (same with/without instruct prefix) |
| MRR | 0.124 | 0.129 | **0.918** |
| query latency p50 / p95 | 202 / 210 ms | — | **32 / 38 ms** |
| mean distance: relevant vs not | 0.202 / 0.228 | 0.152 / 0.172 | **0.394 / 0.646** |
| F1-optimal `max_cosine_distance` | 0.127 (F1 0.09) | 0.10 (F1 0.06) | **0.43–0.447 (F1 0.80)** |
| dims | 768 | 768 | 1024 |

Sanity probe on the FLM build: identical text pairs score 0.999, but a paraphrase scores
0.742 vs 0.721 for *unrelated* text — the embedding space is collapsed. The NPU/FLM
conversion of embed-gemma is semantically near-useless regardless of prompts; with the
old fixed 0.35 threshold, production recall was effectively top-k noise.

Slot behaviour (the decision's open question): the GGUF embedder loads into Lemonade's
embedding slot on GPU **alongside** Flash-Next (93.7 GB) — no LLM eviction observed.

## Actions taken

- `EMBEDDING_MODEL` default → `Qwen3-Embedding-0.6B-GGUF-Q8_0` (pull:
  `lemonade pull Qwen/Qwen3-Embedding-0.6B-GGUF:Q8_0`).
- New `EMBEDDING_MAX_COSINE_DISTANCE` setting (decision 6's per-model threshold);
  0.35 remains the generic default, **0.45** is the calibrated value for Qwen3 and is
  set in the live config. The retriever reads it per request.
- No query/doc prefixes: raw text scored identically to instruct-prefixed for Qwen3.
- `embedding_space_id` handles the swap: new rows stamp the new space, old-space rows
  stay invisible to cosine recall (FTS still finds them) until a re-embed run.

## Still open

- Re-run on a real-chat corpus once the live DB accumulates history.
