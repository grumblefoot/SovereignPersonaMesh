# Sovereign Persona Mesh (SPM) - v0.3 Release Notes

## What's New in v0.3
v0.3 brings a major architectural overhaul to the Game Master (GM) subsystem. It introduces a powerful hybrid streaming pipeline that securely isolates the Game Master's internal logic and world-enforcement planning from the public-facing character persona.

### Features
* **Hybrid Stream Parsing Pipeline:** Implemented a new model-native `<think>` tag system combined with Markdown horizontal rule (`---`) boundaries. This creates a rock-solid separation between the LLM's internal scratchpad and its character dialogue, preventing monologue bleed-through into the UI.
* **Stream Parser Extraction Engine:** The `stream_parser` now actively extracts `[GM WARNING: ...]` notices generated within the Game Master's scratchpad and automatically appends them to the end of the public response stream. This bypasses long-context "forgetfulness" in LLMs, guaranteeing that critical rule violations are successfully communicated to the player.
* **Natural Rule Enforcement:** Removed strict application halts on rule violations. Instead, the Game Master is dynamically instructed to note rule/lore violations in its scratchpad, reject hallucinations naturally in-character, and apply narrative consequences seamlessly.
* **Telemetry Hydration Fixes:** Fixed a critical bug in `telemetry.py` where SQL insertions were missing the `public_response` column and variables were mismatched.
* **Database Updates:** The PostgreSQL vector schema (`csa_memory_{character_id}`) has been updated to automatically provision a `public_response` column for storing the final cleaned canonical text output.

### Known Issues
* The Automated Scenario Builder (`csa_lore_rules` auto-population) is not yet implemented.
* The periodic "State of the World" dynamic context update (to track progressing narratives) is pending development.
